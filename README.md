# Space Physics Scripts

A collection of atmosphere/ionosphere/magnetosphere physics scripts, one
folder per topic. Each folder holds the final version of that script — earlier
drafts and dead ends were left out of this repo.

(HEIMDALL radar/riometer analysis lives in its own repo:
[heimdall-radar-analysis](../heimdall-radar-analysis).)

## Layout

| Folder | Description |
|---|---|
| [`atmospheric_pressure/`](atmospheric_pressure) | Atmospheric pressure variation with altitude and scale height, using constant vs. variable gravity. |
| [`optical_depth_flux/`](optical_depth_flux) | Optical depth and solar flux attenuation through the atmosphere at several solar zenith angles. |
| [`photoionization/`](photoionization) | Photoionization: production rates and ionization profiles from solar irradiance. |
| [`ion_chemistry/`](ion_chemistry) | Ion chemistry model of the ionosphere. |
| [`magnetospheric_currents/`](magnetospheric_currents) | Magnetospheric current systems (noon-midnight B-field model). |

## Data requirements

Small reference/data files (`MSIS.dat`, `IRI.dat`, `phot_abs.dat`,
`phot_ion.dat`) are included directly in each folder.

The following inputs were **left out** because they're too large for a git
repo without LFS (irradiance tables are ~9-11 MB each and largely duplicated
between tasks). Scripts that need them expect the file in their own working
directory:

- `optical_depth_flux/` and `photoionization/` — `irradiance_X{0,15,30,45,60,75,85}.txt`
  (generated by `optical_depth_flux/optical_depth_and_flux.py`, then consumed
  by `photoionization/prog_task_3.py`)
- `magnetospheric_currents/` — `noon-midnight-B-fields.mat`

## Requirements

Scripts use `numpy`, `scipy`, and `matplotlib`.
